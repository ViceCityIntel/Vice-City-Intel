# VICE CITY INTEL starter website

A responsive, editable static website starter built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Publish for free with Cloudflare Pages
1. Create a GitHub repository named `vice-city-intel`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In Cloudflare, create a Pages project and connect the GitHub repository.
4. Choose the static/None framework preset. Leave build command blank and set output directory to `/`.
5. Deploy.

## Customise
- Edit `styles.css` to change colours, spacing, fonts and layout. Main colour variables are at the top.
- Edit `index.html` to change page text and add article cards.
- Edit `script.js` for interactions.

## Important before launch
- The newsletter form is a visual demo only. Connect a real, consent-based newsletter signup (for example, a Beehiiv embed) before collecting email addresses.
- Replace sample article copy with researched, original material.
- Use only original or properly licensed imagery. This starter uses CSS artwork rather than Rockstar assets.
